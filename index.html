01 · Podatki

Tekme prek API

Podatki iz football-data.org se pripravijo dvakrat na dan. API ključ je shranjen kot skrivnost v GitHub Actions, zato ga tukaj ni treba vnašati.

Podatki še niso uvoženi.

Rezervni uvoz CSV

Uporabi, če objavljeni podatki niso na voljo. CSV mora vsebovati stolpce Date,HomeTeam,AwayTeam,FTHG,FTAG. Sprejme datume YYYY-MM-DD ali DD/MM/YYYY ter eno ligo na datoteko.

Bližnje tekme

Tekme za preverjanje kvot

Prikazanih je pet bližnjih tekem z visoko ocenjeno verjetnostjo. To niso predlogi za stave: tudi favorit pri prenizki kvoti nima pozitivne vrednosti. Model še ni umerjen.

02 · Napoved

Preveri tekmo

Primerjaj vse tri kvote

Prepiši trenutne kvote 1 / X / 2 iz E-stav za isto tekmo in osnovni izid po rednem delu. Kvote se lahko spremenijo.

Preverjanje

Kako se je model odrezal za nazaj?

Za vsako že odigrano tekmo uporabi samo rezultate pred njenim datumom. Oceno primerja s preprostim izhodiščem: deleži 1 / X / 2 na prejšnjih tekmah iste lige.

Ni primerjave z dejanskimi kvotami, zato ta pregled ne meri donosnosti. Iste podatke uporabljava tudi pri razvoju modela; za zanesljiv sklep bodo potrebne nove, vnaprej shranjene napovedi.

03 · Evidenca

Zabeleži napoved

»Pozitivna vrednost« je samo izračun iz ocene modela. Model še ni umerjen na novih tekmah, zato to ni priporočilo za vložek.

Dnevnik

Shranjene napovedi

API ob osvežitvi prenese tekme in zaključi povezane napovedi po uradnem rezultatu. Kvote vnesi ročno ob času napovedi. Podatki ostanejo samo v tem brskalniku; uporabi »Izvozi moje podatke« za varnostno kopijo. Samodejnega osveževanja v ozadju in sinhronizacije med napravami ni.
